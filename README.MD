# Projeto Git Laboratório

Projeto desenvolvido para a disciplina de Coding 
do curso de Análise e Desenvolvimento de Sistemas.

## Objetivo

Demonstrar, de forma prática, os principais conceitos de
controle de versão utilizando Git e GitHub.

## Tecnologias

- HTML
- CSS
- Git
- GitHub

## Conceitos praticados

- Inicialização de repositório
- Git status
- Staging
- Commits
- Histórico
- Git diff
- Git show
- Git revert
- Branch principal
- Repositório remoto
- Git push
