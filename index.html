Laboratório Git: Evolucao em Versão

Uma demonstração prática de como um projeto evolui através do controle de versão.

O que estamos aprendendo com o Git?

  • Registrar diferentes versões do projeto.
  • Identificar alterações realizadas nos arquivos.
  • Comparar versões utilizando o git diff.
  • Desfazer alterações sem apagar o histórico.
  • Publicar o projeto utilizando o GitHub.

Evolução do projeto

01

Criação

O projeto é criado e sua primeira versão é registrada.

02

Evolução

Novos conteúdos e funcionalidades são adicionados.

03

Versionamento

Cada alteração importante pode ser registrada em um commit.

04

Reversão

Uma alteração pode ser desfeita utilizando o git revert, preservando o histórico.

Comandos praticados

git init git status git add . git commit git log git diff git revert git push
